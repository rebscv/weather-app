# Weather App

A weather application built with React that retrieves weather data from the [Open-Meteo API](https://open-meteo.com/). This project is part of my ongoing development in React and modern front-end development.

## Features

- Search for a city to retrieve weather information
- Display current weather data, including temperature, humidity and wind speed
- Fetch data from an external weather API
- Build reusable React components
- Manage application state using React Hooks

## Technologies

- React
- JavaScript (ES6+)
- Vite
- HTML5
- CSS3
- Open-Meteo API

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rebscv/weather-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd weather-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
